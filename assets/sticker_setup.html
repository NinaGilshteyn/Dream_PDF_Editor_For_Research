⚡ Sticker generation setup

Enter your OpenAI API key once for this running service. It stays in memory on this computer; it is not saved in the article HTML or on disk.

Generating a sticker uses your OpenAI API account. API usage is separate from using the ChatGPT app. Only your sticker description is sent when you click Generate; your article and notes are not sent. Restarting the service clears the key.
